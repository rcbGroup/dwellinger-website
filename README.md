# Dwellinger.co.uk

The UK's national design, build, and property intelligence platform.

## Tech Stack

- **Next.js 14** App Router + TypeScript
- **Tailwind CSS** with custom dark design system
- **PWA** — manifest + service worker (installable on Android/iOS)
- **Vercel** deployment

## Design System

- Background: `#0A0A0A`
- Accent: `#F59E0B` (amber)
- Text: `#FFFFFF` / `#A1A1AA` secondary
